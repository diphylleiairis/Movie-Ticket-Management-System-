# Documentation

- `requirements/`: approved requirements, project descriptions, and product backlog source files.
- `planning/`: sprint plans, dashboards, and delivery planning files.
- `design/`: architecture, UI, data-model, and test-design documents.
- `reports/`: completed academic, testing, and release reports.
- `adr/`: short records of important project decisions.
